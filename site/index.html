API telemetry

Watch an API breathe, in real time.

QuakeScope serves earthquake data from the USGS Earthquake API and measures itself while it runs. Prometheus collects the numbers and Grafana turns them into a live dashboard.

Open live graphs → Grafana dashboard

What we measure

The earthquake data is only the example. The project is about three numbers every team watches.

Request rateHow many requests the API receives every second.
LatencyHow long those requests take, shown as p50, p95 and p99.
Error rateThe share of requests that fail with a server error.

How it fits together

  1. The load generator sends normal requests to the API, about five per second.
  2. The API answers them, asking USGS for data when needed and reusing answers for 60 seconds. It counts and times every request.
  3. The metrics page. The API publishes those counts as plain text at /metrics.
  4. Prometheus reads /metrics every 5 seconds and stores each number with the time.
  5. Grafana asks Prometheus for the numbers and draws the dashboard. The Live graphs page draws the same data.
